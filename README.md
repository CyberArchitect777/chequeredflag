
# Chequered Flag

Chequered Flag is a Java-based open-source editor for Geoff Crammond's Formula One Grand Prix / World Circuit. Development originally began in 2005 and continued for approximately three years until 2008.

This repository is a preservation and restoration of the original CVS repository previously hosted on SourceForge. The original commit history, tags and contributor information have been retained and migrated to Git where possible.

## Historical Context

Development of Chequered Flag originally took place using the CVS version control system and the Java-based NetBeans IDE.

The original CVS repository was recovered and migrated to Git in 2026.

The original contributors identified in the CVS history include:

- Klaus Six
- Barrie Millar
- René Smit

## Repository Status

This repository currently serves primarily as a historical archive of the original project. There are no guarantees as to:

- Build compatibility with modern Java versions (although it appears to still build using modern Java versions as of 2026)
- Runtime stability
- Documentation quality

## CVS to Git Migration Notes

The original CVS repository was migrated using modern conversion tooling. Due to differences between CVS and Git, some historical branch and tag reconstruction may not perfectly reflect the original repository structure.

Original contributor usernames have been preserved or mapped where possible.
